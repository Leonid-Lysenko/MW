# Документация NLP-модуля

## Общие сведения

**Модуль**: Гибридный экстрактор медицинских симптомов  
**Назначение**: Извлечение симптомов из неструктурированного текста на русском языке  
**Язык**: Python 3.12  
**Архитектура**: Гибридная (Rule-based + NER + семантический поиск)

## Компоненты модуля

### 1. Rule-based экстрактор
- **Назначение**: Поиск симптомов по точному совпадению с синонимами, обработка отрицаний
- **Словарь**: 2034 фразы-синонима для 304 симптомов
- **Обработка отрицаний**: Лингвистические правила (маркеры: "нет", "не", "без")

### 2. NER-модель (RuBioRoBERTa)
- **Модель**: RuBioRoBERTa (дообученная)
- **Разметка**: BIO (B-SYMP, I-SYMP, O)
- **Обучающая выборка**: 2541 фраза
- **Тестовая выборка**: 544 фразы
- **F1-мера (токен-уровень)**: 0.931

### 3. Семантический поиск
- **Модель**: multilingual-E5-large (HuggingFace)
- **Векторная БД**: pgvector (PostgreSQL)
- **Размерность эмбеддингов**: 1024

### 4. Гибридный алгоритм
- **Приоритет**: Rule-based → NER → семантический поиск
- **Rule-based**: основа (уверенность 1.0)
- **NER**: дополнение для топ-74 симптомов (порог 0.75)
- **Семантический поиск**: резервный канал (порог 0.85/0.75)

## Результаты тестирования

| Подход | Macro F1 | Micro F1 | Weighted F1 |
|--------|----------|----------|-------------|
| Rule-based | 0.705 | 0.731 | 0.698 |
| Семантический поиск | 0.422 | 0.432 | 0.457 |
| NER (RuBioRoBERTa) | 0.414 | 0.434 | 0.404 |
